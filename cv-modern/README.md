# cv-modern

Bilingual CV (EN + ES) with shared `layout.sty` and `preamble.tex`.

## Build

```bash
make        # both PDFs
make en     # English
make es     # Spanish
make clean
make distclean
```

## Outputs

| Language | Path |
|----------|------|
| English | `build/en/CV_von_Bergen_Sebastian.pdf` |
| Spanish | `build/es/CV_von_Bergen_Sebastian_es.pdf` |

Content: `content/en/` and `content/es/` (mirrored structure). Photo: `../images/CV_photo.png`.
